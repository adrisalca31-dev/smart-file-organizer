# Smart File Organizer

## Project Overview

### Problem Statement

People often accumulate many different types of files in a single folder, such as the Downloads folder. Over time, this makes it difficult to locate files and keep the workspace organized.

### Project Goal

Develop a Python application that automatically organizes files into folders based on their file type.

### Target Users

- Students
- Office workers
- Home users
- Anyone who wants to keep their files organized

### Current Version

v0.1.0 (Planning)

### Project Status

Planning

## High-Level Algorithm

1. Select the folder to organize.
2. Read all files inside the selected folder.
3. Process each file one by one.
4. Identify the file extension.
5. Determine the correct destination folder.
6. Create the destination folder if it does not exist.
7. Move the file to its destination.
8. Repeat until all files have been processed.
9. Display a summary of the operation.

## MVP Features (Version 1.0)

- Select a folder to organize.
- Scan all files in the selected folder.
- Detect the file extension.
- Create destination folders automatically.
- Move files into the correct folder.
- Display a summary of the operation.
